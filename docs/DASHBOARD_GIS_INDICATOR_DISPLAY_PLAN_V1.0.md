# 罗宜高速 ESG 首页指标地图显示方案 V1.0

更新时间：2026-07-17

## 1. 设计目标

首页 GIS 不再只是路线背景，而应承担“空间化解释首页指标”的作用。基于当前测试数据，地图需要回答三类问题：

1. 当前问题在哪里；
2. 问题属于 E/S/G 哪类指标；
3. 点击空间要素后，能跳转到哪一个指标弹窗查看来源明细。

当前阶段建议坚持领导层口径：只查看、只定位、只督办预留，不在地图侧办理事项。

## 2. 当前地图基础

### 2.1 底图

正式底图：

```text
Cesium + 高德在线卫星影像
```

当前高德底图使用 GCJ-02 坐标系，业务数据源为 WGS84 / EPSG:4326。前端已在展示层做 WGS84 → GCJ-02 转换，不改变数据库、SHP、GeoJSON 或 API 原始坐标。

### 2.2 当前业务图层

| 图层 | 类型 | objectType | 当前来源 |
|---|---|---|---|

## 3. 首页指标与地图表达关系

### 3.1 当前优先空间化指标

| 指标 | 首页数值 | 地图表达 | 点击后动作 |
|---|---:|---|---|
| E01 环境监测超标项次 | 2 | 监测点闪烁/小红点；按扬尘、噪声分类 | 打开 E01 弹窗并筛选对应监测点 |
| E02 未闭环环保问题 | 5 | 环保问题点/区域面；与弃渣点、水源保护区、生态区关联 | 已接入：打开 E02 并高亮来源记录 |
| E03 未闭环水保问题 | 7 | 水保问题点/敏感区面；优先叠加弃渣点、水源保护区 | 后续打开 E03 并定位记录 |
| S02 较大及以上安全风险点 | 6 | 风险点图标；边坡监测点、施工风险点突出 | 已接入：打开 S02 并高亮来源记录 |
| G02 临期及逾期许可事项 | 5 | 与许可涉及标段/工点挂接；临期橙色、逾期红色 | 后续打开 G02 并定位许可事项 |
| G03 未关闭整改事项 | 6 | 整改事项点/标段关联；逾期红色边框 | 后续打开 G03 并定位整改事项 |

### 3.2 不建议强行空间化的指标

| 指标 | 原因 | 建议展示 |
|---|---|---|
| S01 连续安全生产天数 | 项目级指标，不天然对应单点 | 在路线整体上显示“连续计数中 / 368天”总览徽标 |
| S03 劳务纠纷 | 更多对应班组/单位/合同段，不一定有精确坐标 | 可按标段聚合，不显示具体个人/敏感点 |
| S04 群众诉求 | 可能涉及隐私和敏感位置 | 只做标段/乡镇级聚合 |
| E04 碳排放强度 | 多为材料、能源、设备活动数据 | 按施工区段/拌合站/运输线路聚合展示 |
| G01 合规手续 | 多为流程事项 | 按受影响节点或标段聚合 |
| G04 合规资料缺口 | 资料类指标 | 可在资料侧栏展示，不建议地图主显 |

## 4. 地图显示层级设计

### 4.1 默认视图

默认显示：

- 三个标段路线；
- 关键环保敏感区；
- 当前风险点；
- 右下角或要素点击后显示业务摘要。

默认不显示：

- 全部 KPI 明细点；
- 大量资料类事项；
- 办理/处置按钮。

### 4.2 模式切换

| 按钮 | 显示内容 |
|---|---|
| 全线 | 标段路线 + 重点环保点位 + 风险点摘要 |
| 标段 | 1/2/3 标段路线、标段标签、关联事项数量 |
| 环保点位 | E01/E02/E03 相关监测点、环保问题、敏感区 |
| 风险点 | S02 风险点、边坡监测点、预警状态 |
| 复位 | 回到罗宜高速项目范围 |

### 4.3 颜色规则

| 状态 | 建议颜色 | 说明 |
|---|---|---|
| 正常 | 青绿 | 可控、已闭环、正常监测 |
| 关注 | 黄色/橙色 | 临期、待复查、待确认 |
| 预警 | 红色 | 逾期、超标、较大风险 |
| 离线/无数据 | 灰色 | 设备离线、数据缺失 |
| 标段路线 | 青蓝/绿色发光 | 保持大屏视觉连续性 |

## 5. 要素点击卡片

### 5.1 领导首页 dashboard 模式

点击要素后只显示摘要：

- 要素名称；
- 状态；
- 关联事项总数；
- 待处理数；
- 高风险/逾期数；
- 事项类型 chips，例如“环保问题 2”“安全风险 1”；
- “查看关联业务”按钮。

不显示：

- 数据库表名；
- 原始字段全集；
- 办理、处置、确认、审核按钮。

### 5.2 GIS 预览 preview 模式

用于调试，可展示：

- 完整 properties；
- sourceTable；
- sourceId；
- updatedAt；
- 关联业务完整列表。

## 7. 测试数据下的首页地图方案

基于当前首页测试值，建议默认地图摘要如下：

| 地图摘要项 | 数值 | 取数/说明 |
|---|---:|---|
| 合规点位 | 12 | 当前合规保障面板示例值 |
| 碳排点位 | 6 | 当前碳排/活动数据周期或点位聚合示例 |
| 敏感区 | 3 | 水源保护区 2 + 生态保护区 1 |
| 风险点 | 6 | S02 较大及以上风险点 |

地图上重点显示：

- 三个标段路线；
- 两个弃渣点；
- 两个水源保护区；
- 一个生态保护区；
- 两个边坡监测点；
- E02/S02 可跳转的关联业务线索。

## 8. 数据结构建议

建议后端逐步形成统一 GIS 业务关联表或视图：

```text
gis_feature
gis_feature_business_link
```

核心字段：

| 字段 | 说明 |
|---|---|
| feature_id | GIS 要素 ID |
| object_type | road-section / spoil-site / water-source / slope-monitor 等 |
| source_table | 业务来源表 |
| source_id | 业务来源记录 ID |
| target_kpi_code | E01/E02/S02/G02 等 |
| status | normal / attention / warning / critical |
| status_label | 中文状态 |
| risk_level | 风险等级 |
| title | 事项标题 |
| summary | 领导层摘要 |
| updated_at | 更新时间 |

## 9. 当前注意事项

1. 当前高德卫星底图使用 GCJ-02，业务数据仍为 WGS84，前端展示层已转换；
2. 不要把转换后的 GCJ-02 坐标写回数据库；
3. 如果后续改用天地图/政务内网 WGS84 影像，应把底图 `coordinateSystem` 改回 `wgs84`；
4. 首页 dashboard 模式不要出现配置后台按钮；
5. 地图侧不办理业务，只做定位、查看和跳转；
6. 对群众诉求、劳务纠纷等敏感数据，只建议标段级/区域级聚合，不建议暴露精确坐标。

## 10. 下一步建议

1. 扩展 E01/E03/G02/G03 的 GIS 来源跳转协议；
2. 增加地图顶部摘要指标的真实 API；
3. 为 E02/S02 以外的业务表补 `gis_feature_id` 或关联视图；
4. 样式上降低路线发光强度，让卫星底图纹理更清楚；
5. 在 `/gis-preview` 增加“坐标系诊断”显示：当前底图坐标系、业务数据坐标系、是否启用展示转换。
