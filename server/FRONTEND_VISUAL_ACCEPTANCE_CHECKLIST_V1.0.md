# 前端视觉验收清单 V1.0

更新时间：2026-07-17

本清单用于前端样式同事完成视觉统一后进行验收。验收重点是视觉、布局、交互层级，不重新定义数据口径和 API 逻辑。

## 1. 通用验收环境

建议分辨率：

```text
1920 × 1080
```

访问地址：

```text
领导首页：http://localhost:5174/#/
工作台：http://localhost:5174/#/workspace
GIS 预览：http://localhost:5174/#/gis-preview
```

验收命令：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\run-local-acceptance.ps1 -SkipBuild
```

最终验收：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\run-local-acceptance.ps1 -Full
```

## 2. 领导首页整体

| 检查项 | 标准 |
|---|---|
| 页面整体 | 1920×1080 下无浏览器页面滚动条 |
| 顶部导航 | 文字清晰，选中态明显，不挤压标题 |
| E/S/G KPI 卡片 | 三组高度一致，数字字号统一，单位不贴边 |
| GIS 区域 | 与右侧专题、底部时间轴不重叠 |
| 右侧专题 | 三块面板间距均匀，不出现内容溢出 |
| 底部时间轴 | 节点文字不重叠，当前节点突出 |
| 色彩 | E 绿色、S 蓝色、G 紫色逻辑保持一致 |

## 3. KPI 弹窗

| 检查项 | 标准 |
|---|---|
| 弹窗尺寸 | 不接近全屏，背景首页仍可感知 |
| 标题栏 | KPI 编码、标题、关闭按钮清晰 |
| 顶部摘要 | 数字/单位对齐，不换行错乱 |
| 主图区域 | 图表标题清晰，图例不遮挡 |
| 右侧摘要 | 文案不截断，重点信息可扫读 |
| 明细表格 | 表头、行高、状态标签统一 |
| 底部按钮 | “查看详情/发起督办/关闭”等按钮不贴边 |
| 来源时间 | 数据来源和更新时间可读，不抢主视觉 |

特殊检查：

- E02 主状态不出现“逾期”主状态；
- S02 不出现“治理中”，统一为“持续管控/正常管控”；
- G03 主图仍以“整改状态构成”为主；
- GIS 来源打开 E02/S02 时不显示“发起督办”。

## 4. S01 专属弹窗

| 检查项 | 标准 |
|---|---|
| 尺寸 | 建议 80–82vw、76–80vh，不能接近全屏 |
| 核心数字 | “368天”突出但不过度巨大 |
| 时间流程 | 一条完整绿色连续线，不使用月份宫格 |
| 工期流程 | 4 个主阶段，主体工程施工为当前阶段 |
| 并行施工 | “路基｜桥梁｜隧道并行施工”表达为并行 |
| 本轮结论 | 不被底部按钮遮挡 |
| 底部操作 | “查看事故记录”“关闭”可点击 |
| 滚动条 | 弹窗内部不应出现纵向/横向滚动条 |

## 5. 右侧专题面板

### 5.1 合规保障与风险防控成效

- 4 个顶部指标卡尺寸一致；
- 成效构成条形图标签不挤压；
- 重点保障事项最多 3 条时可完整展示；
- 数字 12 / 8 / 0 / 0 不被截断。

### 5.2 碳足迹与低碳增益

- 来源构成包含 4 类；
- 颜色保持：
  - 施工用油：蓝色；
  - 施工用电：绿色；
  - 主要材料：紫色；
  - 其他：橙色；
- “低碳措施成本影响”不表达为已确认财务收益；
- 单位 `tCO₂e` 显示正常。

### 5.3 月报准备与输出

- 进度环 82%/95% 等数字居中；
- “待补资料”“待确认”不截断；
- 不再出现“待补资料清单（示例）”；
- 当前状态、预计完成日期文案清晰。

## 6. 专题弹窗

### 碳足迹专题

- 5 个标签页切换清晰；
- 累计碳足迹图表标题为“月度排放与累计碳足迹趋势”；
- 来源构成合计视觉上接近 100%；
- 成本影响说明不误导为财务收益；
- 主要措施表格不溢出。

### 月报专题

- E/S/G 进度条颜色和标签统一；
- 章节清单可读；
- 缺项清单筛选可见；
- 状态链当前节点突出；
- 不出现上传、编辑、发布类按钮。

## 7. 数据填报与上传工作台

### P01 首页

- 状态卡 27/12/3/5/3/36 清晰；
- 智能入库快捷区按钮大小一致；
- 任务列表列宽合理；
- 右侧智能助手不遮挡内容。

### P02 我的上传任务

- 筛选区标签明确，不使用 E/S/G 代号代替完整含义；
- 表格多列不拥挤；
- 批量按钮禁用态清晰；
- 分页区域对齐。

### P03 ESG 智能入库

- 上传区域醒目；
- 解析队列状态清晰；
- AI 解析摘要字段可读；
- 候选任务匹配度条不溢出；
- 确认入库按钮位置稳定。

### P04 审核结果

- 左侧列表和右侧详情联动视觉明确；
- 待审核按钮“审核通过/审核退回”不拥挤；
- 补正要求状态标签清晰；
- 审核轨迹时间线不乱。

### P05 资料中心

- 左侧分类树层级清楚；
- 资料列表行高统一；
- 右侧详情信息密度适中；
- 版本、关联任务、标签不溢出；
- 操作按钮间距至少 8px。

## 8. GIS 区域

默认：

```ts
useRealGisOnDashboard: true
```

如需应急回退，可临时改为：

```ts
useRealGisOnDashboard: false
```

检查项：

- 首页真实 GIS 不遮挡右侧专题；
- 不遮挡底部时间轴；
- 不显示“配置后台”按钮；
- 图层按钮紧凑；
- FeatureCard 不越界；
- BusinessLinksPanel 不越界；
- 点击 E02/S02 来源后弹窗高亮正常；
- 关闭后恢复首页状态；
- 验收完必须改回 `false`。

## 9. 不允许出现的问题

- 页面级滚动条；
- 弹窗内容被底部操作栏遮挡；
- 表格横向滚动条；
- 重要数字换行；
- 状态标签颜色混乱；
- “办理/处置/督办”出现在 GIS 来源查看链路；
- `useRealGisOnDashboard` 被误改回 `false`；
- API fallback 被删除导致后端关闭时页面空白。

## 10. 视觉验收完成后必须执行

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\run-local-acceptance.ps1 -Full
```

通过后再进入阶段统合。
