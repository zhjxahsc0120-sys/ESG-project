## 4. 推荐执行顺序

```text

3. 数据质量规则和字段映射规则配置化
```

## 5. 每条链路统一交付要求

每补一条动态链路，都必须同时交付：

1. 文档类型或接口来源识别；
2. 字段映射；
3. 业务表写入或更新逻辑；
4. 首页 KPI 动态聚合；
5. 弹窗详情动态聚合；
6. 自动化测试；
7. `reset_acceptance_baseline.py` 复位逻辑；
8. `run-local-acceptance.ps1 -Full` 纳入验收。

## 6. 不建议现在混做的事项

暂不建议和动态刷新链路混在一起做：

- 领导督办真实流程：涉及权限和流程；
- 月报自动生成：应等月报资料确认和章节状态稳定；
- GIS 默认替换首页 SVG：仍按灰度开关推进；
- 前端字体、间距、视觉样式：由样式同事并行处理，后端只保证接口和数据口径。
