# 罗宜高速 ESG 领导层看板产品需求文档

## 1. 产品概述

罗宜高速 ESG 数据平台——领导层看板是一款面向高速公路建设项目管理层的大屏数据可视化产品，用于集中呈现环境（E）、社会（S）、治理（G）三大维度的关键指标、GIS 空间态势、合规风险防控成效、碳足迹与低碳增益、月报准备进度以及建设阶段进展。

产品目标：为项目决策者提供一屏掌握 ESG 全貌的能力，支持从宏观 KPI 到空间点位、从合规风险到月报输出的多层级信息快速获取。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 项目领导/管理层 | 大屏展示 | 查看全部 KPI、GIS 态势、风险、碳排、月报与阶段进展 |
| 平台运营人员 | 后台配置 | 维护指标阈值、点位数据、月报材料清单等（本版本仅展示层） |

### 2.2 功能模块

1. **顶部导航**：系统标题、主导航按钮，当前激活“工作台首页”。
2. **E/S/G 指标卡**：环境环保、社会责任、治理合规三组核心 KPI。
3. **GIS 地图主视觉**：静态底图 + SVG 路线、合规/碳排/风险/敏感区点位、图层切换、卫星/无人机影像对比。
4. **合规保障与风险防控成效**：4 个顶部指标卡 + 横向条形图 + 重点保障事项列表。
5. **碳足迹与低碳增益**：3 个顶部指标卡 + 环形图 + 减排措施列表。
6. **月报准备与输出**：进度环 + 状态块 + 待补资料清单表格。
7. **建设阶段时间轴**：11 个阶段节点，标识当前阶段与已完成阶段。

### 2.3 页面模块详述

| 页面/区域 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 工作台首页 | HeaderNav | 展示系统标题与导航按钮，支持 hover 高亮 |
| 工作台首页 | TopKpiGroups | E/S/G 三组 KPI，每组 4 个指标卡，显示总体可控状态 |
| 工作台首页 | GisOverviewPanel | GIS 主视觉，包含路线、点位、风险区、图例、图层切换、卫星对比 |
| 工作台首页 | ComplianceRiskPanel | 合规风险指标、成效构成条形图、重点保障事项 |
| 工作台首页 | CarbonBenefitPanel | 碳足迹指标、来源构成环形图、减排措施贡献 |
| 工作台首页 | MonthlyReportPanel | 月报进度、状态、待补资料清单 |
| 工作台首页 | ConstructionTimeline | 11 阶段建设时间轴，当前第 6 阶段高亮 |

## 3. 核心流程

用户进入大屏后，页面以无滚动一屏方式呈现全部信息。用户可：

1. 查看顶部 E/S/G 核心指标与总体状态。
2. 通过 GIS 地图快速识别合规、碳排、风险、敏感区空间分布。
3. 切换图层按钮，筛选全线/标段/环保点位/风险点/无人机影像。
4. 查看右侧合规风险、碳足迹、月报准备的详细数据与图表。
5. 通过底部时间轴了解当前建设阶段位置。

```mermaid

    A["打开大屏"] --> B["加载 E/S/G KPI"]
    B --> C["渲染 GIS 地图与点位"]
    C --> D["加载右侧分析模块"]
    D --> E["渲染底部时间轴"]
    E --> F["用户交互：hover/图层切换/数据下钻"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：深色科技感大屏驾驶舱，霓虹微光边框，半透明面板。
- **主背景**：`#020b18`
- **面板背景**：`rgba(5, 18, 38, 0.88)`
- **主文字**：`#e8f3ff`
- **次要文字**：`#8fa9c8`
- **主题色**：
  - 环境 E：`#69e36f`（绿）
  - 社会 S：`#2f9cff`（蓝）
  - 治理 G：`#a66cff`（紫）
  - 强调/信息：`#00e5ff`（青）
  - 警告：`#ffb347`
  - 危险：`#ff4f5e`
- **边框**：`rgba(0, 174, 255, 0.55)`，带轻微发光效果。
- **字体**：系统默认无衬线字体为主，KPI 数字使用大字号、高亮色、等宽感数字字体优先。
- **图标**：使用 lucide-vue-next 或自定义 SVG，保持科技简洁风格。

### 4.2 页面布局

页面固定 16:9 比例优先，1920×1080 一屏无滚动。

```text
┌─────────────────────────────────────────────────────────────┐
│ HeaderNav（标题 + 导航，约 9% 高度）                         │
├─────────────────────────────────────────────────────────────┤
│ TopKpiGroups（E/S/G 三组指标，约 17% 高度）                  │
├──────────────────────────────┬──────────────────────────────┤
│                              │ ComplianceRiskPanel          │
│   GisOverviewPanel           │（右上）                       │
│   （左侧主视图，约 66% 宽）   ├──────────────────────────────┤
│                              │ CarbonBenefitPanel           │
│                              │（右中）                       │
├──────────────────────────────┼──────────────────────────────┤
│ ConstructionTimeline         │ MonthlyReportPanel           │
│（左侧底部，与 GIS 同宽）      │（右下）                       │
└──────────────────────────────┴──────────────────────────────┘
```

### 4.3 响应式

- **优先分辨率**：1920×1080。
- **兼容方案**：1366×768 等较小屏幕通过整体等比缩放适配。
- **原则**：大屏一屏展示，不出现纵向滚动条。

### 4.4 动效与交互

- 顶部导航 hover：蓝色边框亮起。
- KPI 卡 hover：微弱放大 + 发光。
- 地图点位 hover：显示名称与指标摘要。
- 图层切换按钮：active 状态高亮。
- 时间轴当前阶段：光圈呼吸动画。
- 月报进度环：可动态变化。
- 图表 resize：自动适配容器。
- GIS 中央节点：雷达光圈旋转/扩散动画。

## 6. 非功能需求

- 首屏加载时间 ≤ 3 秒（本地资源）。
- 图表在容器 resize 时自动重绘。
- 无外部地图服务依赖，第一版使用静态 SVG 路线实现。
- 所有文字、数字、点位、图表组件化，便于后续接入接口。
